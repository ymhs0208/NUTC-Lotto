# 校網限定模式

2026-10-06（臺灣時間）。程式與測試已完成，未部署正式站，未修改正式環境設定或防火牆。

後端設定 `CAMPUS_NETWORK_ONLY=true` 時，學生登入與學生 session API 不再共用每 IP 額度。每帳號登入挑戰、每 token 600 次／分鐘、學生與工作人員合計全站 12000 次／分鐘，以及密碼驗證／登入／資料庫工作並行、排隊與逾時限制仍保留。工作人員與健康檢查的限流不變。Node 與 Workers 都支援；不設定或設定非 `true` 字串時維持原規則。

此開關不實作網路白名單。先由防火牆或反向代理限制網站、API 及所有後端入口，再啟用。Workers 需涵蓋自訂網域、workers.dev 與預覽網址，或停用額外公開入口。Node 在 `.env` 設定並重啟；Workers 在環境變數設定並部署。

驗證：TypeScript 檢查、前端建置及 17 項限流／登入挑戰／session 測試通過。新增測試以 IP 額度 1 驗證 500 個學生帳號共用 IP 可通行，也驗證帳號挑戰、單一 token、全站額度及工作人員 IP 上限仍生效。

本機 Node 與真實 workerd 引擎各測試 500 個合成帳號、同一來源 IP、共用密碼、模擬 Supabase 每次請求延遲 30 ms。兩者首次登入 500／500、登入後查詢 500／500、同步重新查詢 500／500，無 429／503、無傳輸錯誤、無資料錯配，未使用重試。紀錄：

- `security/evidence/campus-network-500-node.json`
- `security/evidence/campus-network-500-workers.json`

連線已預熱，使用模擬資料庫與共用密碼；不代表正式校園網路、Supabase 或個別密碼模式的容量保證。
